# الشعار الرسمي

1. في Figma اختر الشعار (طبقة `BO-03 1 1` في شاشة تسجيل الدخول) ← Export ← **PNG** ← حجم 4x أو أكبر، بخلفية شفافة.
2. احفظه باسم **`logo.png`** في هذا المجلد (`branding/logo.png`) وارفعه على GitHub.
3. عند البناء، الـ workflow يشغّل `tools/apply-branding.sh` فيولّد أيقونة التطبيق (Adaptive) وشعار الواجهة تلقائيًا. بدون الملف يبقى الشعار المبدئي.

> مهم: الشعار الحالي في Figma صورة (Raster) وليس Vector، وأنا لا أستطيع نقل الصورة إلى بيئتي، لذلك لازم تصدّرها أنت.
> خلفية أيقونة التطبيق لون `#001716` (الأخضر الداكن)، فاستخدم شعارًا بألوان فاتحة/ذهبية.
