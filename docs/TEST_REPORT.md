## مخاطر معروفة
- احتمال ظهور أخطاء ترجمة صغيرة في أول بناء (لم يُجرَّب المترجم). أرسل الـ Log وسأصلحه.
- IBM Plex Sans Arabic غير مضمّن؛ الخط الافتراضي للنظام.
- الإحداثيات تقريبية والبيانات تجريبية.
- لا يوجد اختبار على أحجام شاشات/أجهزة مختلفة ولا اختبار إمكانية الوصول (TalkBack).

## اختبار يدوي مقترح بعد أول APK
1. تسجيل مشتري ← OTP `1234` ← كلمة مرور ← اشتراك تجريبي ← الرئيسية.
2. فتح عقار ← تفاوض ← الدور ← عرض أقل من الحد (يمنع) ثم أعلى ← دفع تجريبي ← طلباتي (معلقة + اختفاء الإعلان 3 أيام).
3. تسجيل مطور ← إضافة إعلان بصور ← «محاكاة موافقة» ← ظهوره في الرئيسية.
4. محادثة: إرسال/تعديل/حذف/حظر/إرفاق صورة.
5. تغيير اللغة والسمة، حذف الحساب.
