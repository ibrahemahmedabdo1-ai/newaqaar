# قائمة التوافق مع سياسات Google Play

> السياسات بتتغير؛ راجع صفحة «Policy center» في Play Console قبل الرفع. الجدول ده اللي اتنفّذ في الكود واللي لسه عليك.

## ✅ منفّذ في الكود

| البند | ما تم |
|---|---|
| **مستوى API** | `targetSdk = 36`, `compileSdk = 36`, `minSdk = 26`. (Google تطلب API 35+ منذ أغسطس 2025، ومن المتوقع API 36 للتحديثات بعد 31 أغسطس 2026 — تأكد من Play Console.) |
| **صلاحيات أقل ما يمكن** | `INTERNET` و`ACCESS_COARSE_LOCATION` فقط. لا كاميرا، لا تخزين/وسائط (يُستخدم Photo Picker ومنتقي الملفات والكاميرا عبر Intent)، لا إشعارات، لا SMS، لا موقع في الخلفية. |
| **الموقع** | يُطلب وقت الاستخدام فقط من شاشة «إختر المنطقة» مع شرح واضح، تقريبي، ومرتبط بميزة حقيقية («القريب مني»). |
| **حذف الحساب** | داخل التطبيق: الملف الشخصي ← حذف الحساب (يحذف الحساب والإعلانات والطلبات والمحادثات والصور). ورابط ويب في `site/delete-account.html` + `ACCOUNT_DELETION_URL`. |
| **المحتوى الذي ينشئه المستخدم (UGC)** | إبلاغ عن إعلان، حظر مستخدم، حذف/تعديل الرسائل، وحالة «قيد المراجعة» لأي إعلان جديد قبل النشر. |
| **الخصوصية** | شاشة سياسة الخصوصية والشروط داخل التطبيق + صفحات ويب. لا SDK إعلانات ولا تحليلات. كلمات المرور تُخزن كـ Hash (محليًا في النسخة التجريبية). |
| **الأمان** | `allowBackup=false`، استبعاد النسخ الاحتياطي، `cleartextTrafficPermitted=false`، تصغير وتشفير R8 في Release. |
| **16 KB page size** | لا توجد مكتبات native. |
| **Edge-to-edge (Android 15+)** | مفعّل مع التعامل مع الـ Insets. |
| **التحديثات** | Google Play In-App Updates فقط (التحديث الذاتي خارج المتجر مخالف للسياسة، ولم يُستخدم). |
| **حقوق الملكية** | لا صور/شعارات طرف ثالث: رسومات مولّدة، وأزرار الدخول الاجتماعي أحرف فقط. |
| **الشفافية** | شارة «بيانات تجريبية» + ملاحظة أن «مستشارك الذكي» بقواعد بسيطة وليس AI. |

## 🛠 تغطيه لوحة التحكم الجديدة (admin/) — بعد نشرها وربطها
- **الإشراف (UGC):** طابور مراجعة الإعلانات، معالجة البلاغات، إيقاف/حظر المستخدمين، قفل المحادثات، سجل عمليات.
- **صفحات قانونية قابلة للتعديل** من اللوحة + صفحات الويب في `site/`.
- **التحديث الإجباري / الصيانة** من الإعدادات (`minVersionCode`).
- **حذف الحساب** يعمل على الخادم (يتطلب كلمة المرور) ويُبقي سجلات الدفع بدون بيانات تعريفية مباشرة.
- لا يزال عليك: بوابة دفع حقيقية/Play Billing، مزود SMS للـ OTP، سياسة خصوصية تطابق الواقع، استجابة فعلية للبلاغات.

## ⚠️ لازم تعمله قبل النشر (وإلا ممكن الرفض)

1. **ربط خادم حقيقي.** نسخة بدون Backend (بيانات تجريبية، OTP ثابت، دفع وهمي) قد تُرفض تحت **Minimum functionality / Broken functionality / Deceptive behavior**. اربط: مصادقة OTP حقيقية، قاعدة بيانات، رفع صور، مراجعة إعلانات، محادثات. ثم اجعل `DEMO_MODE=false` وأزل البيانات التجريبية (`Demo.kt`) وأرقام/أسماء «تجريبي».
2. **الدفع (Payments policy).**
   - *مبلغ الحجز (1000 ريال + الضريبة)*: خدمة/معاملة عقارية حقيقية ← يجوز استخدام بوابة دفع مرخّصة (مثل Moyasar أو HyperPay أو Tap، وتدعم مدى). نفّذ `PaymentGateway` وادمج SDK/صفحة الدفع الآمنة. لا تخزّن بيانات البطاقة.
   - *اشتراك العميل (320 ريال لمزايا داخل التطبيق)*: إن كان يفتح **مزايا رقمية** داخل التطبيق فلازم **Google Play Billing**. لو كان مجرد خصومات/خدمات فعلية خارج التطبيق فاستشر سياسة Google أو اجعله خارج التطبيق. **الأكثر أمانًا:** Play Billing.
   - صرّح في Play Console بأي ميزة مالية (حجز/ضمان) في Financial features declaration إن انطبق.
3. **Data safety form** — استخدم `docs/DATA_SAFETY.md` وعدّله حسب الخادم الفعلي.
4. **سياسة الخصوصية برابط عام** تتطابق مع الواقع (انشر `site/` على GitHub Pages أو موقعك) وضع الرابط في Play Console وفي `PRIVACY_URL`.
5. **اسم الجهة والتواصل:** حدّث `SUPPORT_EMAIL`/`SUPPORT_WHATSAPP` ومعلومات المطوّر في Play Console (حساب مؤسسة يحتاج رقم D-U-N-S).
6. **تقييم المحتوى** (Content rating) وفئة الجمهور: 18+ (مناسب للتطبيقات العقارية والمعاملات).
7. **تسجيل الدخول الاجتماعي:** إن فعّلته اتبع إرشادات العلامات (Google/X/Apple) ولا تستخدم شعاراتهم بدون التزام بالإرشادات.
8. **المراجعة والإشراف:** لازم يكون عندك فريق/لوحة تراجع الإعلانات والبلاغات فعليًا وتستجيب لها (سياسة UGC).
9. **اختبار مغلق:** حسابات Play الشخصية الجديدة تحتاج اختبار مغلق (عدد مختبرين لعدد أيام محدد) قبل الإنتاج — راجع الشروط الحالية.
10. **أرقام الهواتف:** لا تعرض أرقام حقيقية لأشخاص بدون موافقتهم؛ التطبيق يعرض رقم المعلن فقط لإعلانه ويُنبّهه عند إضافة الإعلان.
11. **الاسم والأيقونة:** الأيقونة الحالية بسيطة؛ استبدلها بشعارك الرسمي (`ic_launcher_foreground.xml`).
